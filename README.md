### Hydra Foundry

**Hydra Foundry** is the name under which I, [Morgan Nichols](https://github.com/Hydrada), a self-taught independent software engineer in Framingham, MA, publish my software. It is an independent practice, not a registered company.

This account is the studio-facing GitHub. My personal profile and the same public portfolio live at **[github.com/Hydrada](https://github.com/Hydrada)**.

I ship local-first desktop tools and Windows apps — Python automation, Electron/Node, .NET/WinUI, and open-source construction software — with day-to-day AI-assisted development.
